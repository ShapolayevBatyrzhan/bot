Клади сюда песни и видео, например `song1.mp3`, `video.mp4`.

Затем в `content.py` укажи путь относительно папки бота:

    {"file": "media/song1.mp3", "title": "Название", "performer": "Исполнитель"},
    VIDEO_FILE = "media/video.mp4"

Ограничения Telegram при загрузке файлом: аудио до 50 МБ, видео до 50 МБ.
Если файл больше — загрузи его в Telegram вручную и используй file_id.

# Телеграм-бот (опрос + плейлист + видео)

Сценарий:

1. `/start` → приветствие с кнопкой **«Да»**
2. 4 сообщения подряд, каждое с кнопкой **«Далее»**
3. Плейлист из 9 песен + подпись под ним (кнопка «Далее»)
4. 5 вопросов:
   - вопросы 1–4: варианты ответа + кнопка **«Свой вариант ответа»**
   - вопрос 5: без вариантов, сразу кнопка **«Написать свой вариант»**,
     после ответа приходит отдельное сообщение
5. Финальный блок с вариантами ответа → на выбор приходит сообщение с кнопкой
6. По кнопке — видео с подписью
7. После видео — финальное сообщение

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env      # и вписать свой токен от @BotFather
python bot.py
```

## Что править

Все тексты, кнопки, песни и видео — в **`content.py`**. `bot.py` трогать не нужно.

### Как подставить песни и видео

В `content.py` в полях `file` (песни) и `VIDEO_FILE` можно указать:

- `file_id` из Telegram — самый быстрый и надёжный вариант;
- путь к локальному файлу, например `media/song1.mp3` (путь считается от папки бота);
- прямую ссылку `https://...`.

Пока стоят заглушки вида `PUT_...` — бот их не отправляет, а шлёт текстовую
строчку вместо файла, чтобы можно было прокликать весь сценарий без медиа.

**Как узнать `file_id`:** пока в `content.py` стоит `SHOW_FILE_ID = True`,
отправь боту в личку песню или видео — он ответит её `file_id`. Нажатие на
`file_id` копирует его. Когда всё вставлено, поставь `SHOW_FILE_ID = False`.

**Локальные файлы:** положи песни в папку `media/` и укажи путь
`media/song1.mp3`. Так проще всего, но каждая отправка заново грузит файл
на серверы Telegram (лимит 50 МБ), поэтому для 9 песен быстрее `file_id`.

## Заметки

- Ответы пользователя пишутся в лог (`Ответ на вопрос N: ...`). Если нужна
  запись в БД или Google-таблицу — добавляется в `save_answer()` в `bot.py`.
- Состояние хранится в памяти (`MemoryStorage`) — после перезапуска бота
  пользователи начинают заново с `/start`. Для постоянного хранения
  подключается Redis-хранилище aiogram.
- `/restart` — пройти сценарий заново.

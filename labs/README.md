## Задание № 2. Решение нелинейных уравнений

### Что сделано

* **Дихотомия** — отрезок `[a, b]` со сменой знака делится пополам; на каждой итерации
  вычисляется ровно одно новое значение `f(x)`. Останов: `|f(x)| < eps` или `b − a < 2·eps`.
* **Касательных (Ньютона)** — `x_{n+1} = x_n − f(x_n)/f'(x_n)`.
  Производная **точная**: функции вычисляются в арифметике дуальных чисел
  (`nm_core.Dual`, forward-mode AD), никаких конечных разностей.
* **Секущих** — производная заменена первой разделённой разностью по двум последним
  итерациям; разгонные точки `x0 = 0.2`, `x1 = x0 + 50·eps`.
* Защита от «зацикливания»: `imax = 30` (для дихотомии больше, у неё линейная сходимость).
* Корень предварительно отделяется: если на `[0, 1]` знаки на концах совпадают,
  отрезок дробится и ищется подотрезок со сменой знака.

### Результат для варианта 1 (`f(x) = −cos(πx/2) + 2x`, eps = 1e−6, x0 = 0.2)

| Метод | Корень | Итераций | \|f(x*)\| |
|---|---|---|---|
| дихотомия | 0.403080940247 | 20 | 1.05e−06 |
| касательных | 0.403081302074 | 3 | 1.31e−08 |
| секущих | 0.403081302146 | 5 | 1.33e−08 |

Уточнённый корень (eps = 1e−15): `x* = 0.40308129760328`.

Вывод: дихотомия сходится линейно (отрезок каждый раз делится пополам, погрешность
падает как `2^−n`), метод касательных имеет сходимость 2-го порядка, секущих — порядка
≈1.618; обоим хватает единиц итераций, но каждая итерация касательных дороже
(нужна `f'(x)`).

## Задание № 3. Интерполирование

### Что сделано

По шагам методички, при `h = 1/n`, `x_j = j·h`, `j = 0..n`:

1. таблица значений `y_j = y(x_j)`;
2. первые разности `Δy_j = y_{j+1} − y_j` и `f[x_j, x_{j+1}] = Δy_j / h`;
3. вторые разделённые разности `f[x_j, x_{j+1}, x_{j+2}] = Δ²y_j / (2h²)`;
4. многочлен Ньютона 2-го порядка

   `P(x) = y_i + (x − x_i)·f[x_i, x_{i+1}] + (x − x_i)(x − x_{i+1})·f[x_i, x_{i+1}, x_{i+2}]`

   вычисляется в узлах с полуцелыми индексами `x_{j+1/2} = x_j + h/2`;
5. погрешности `ε_{j+1/2} = P(x_{j+1/2}) − y(x_{j+1/2})`, затем `ε_max`,
   средний квадрат `<ε²>` и среднеквадратичная погрешность `ε_m = sqrt(<ε²>)`;
6. исследование зависимости `ε_max` и `ε_m` от `n`.

Для узла `x_{j+1/2}` берётся тройка `(x_j, x_{j+1}, x_{j+2})`; у правого края
(`j = n−1`) тройка сдвигается на `(x_{n−2}, x_{n−1}, x_n)` — поэтому в самой правой
точке погрешность меняет знак (точка попадает во второй интервал тройки), это видно
на графике погрешности и является нормальным поведением схемы.

### Проверка

`python3 task3_interpolation.py -v 0` — тестовая функция `y = x²`: `ε_max ≈ 1e−16`,
`ε_m ≈ 4e−17`, т.е. нули с точностью до машинного эпсилон (многочлен 2-й степени
интерполируется точно), как и требует методичка.

### Результат для варианта 1 (`y(x) = sin(πx)`, n = 20)

* `ε_max = 2.396288e−04`
* `<ε²> = 2.920640e−08`
* `ε_m = 1.708988e−04`
